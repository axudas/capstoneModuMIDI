# moduMidi (KiCad)

This is the main board of the ModuMIDI 2 hall-effect keyboard: a KiCad 7 project, which also opens in KiCad 8 and 9.

- Open `moduMidi.kicad_pro`.
- The schematic has the 33 hall sensors (U1–U33, TO-92 lying flat) and the DC jack J1 placed. Nothing is wired yet.
- The board has the 175 × 125 mm outline. Use **Tools → Update PCB from Schematic** to bring the footprints in.
- Parts come from `../libraries/Capstone_Keyboard` (already set up in this project's library tables) and the standard KiCad libraries.

Converted from the LibrePCB project on 2026-11-17.
